# Desk plugins, part 3 (#542)

2026-11-05. `desk_commands` and `api.exec`, typed RPC for plugins, the
CSV example and `docs/desk-plugins.md`.

- **`desk_commands: {<name>: {command, timeout}}`** in `jobshop.yaml` or
  a pack (merged by name and prefixed like pools). The admin method `desk.exec`
  (`{name, input, ticket}`) runs `sh -c` in the root dir with `input` as
  JSON on stdin, 30s default timeout. A non-zero exit or timeout is an
  error with the exit code and stderr. Stdout is `{output}` when it is
  JSON, else `{text}`, at most 1 MiB. Every run is logged with the
  actor; with `ticket` it adds a `desk_exec` history row (`{name, exit,
  error}`) through the new `store.Record`, which does not bump the
  revision. Plugins call it as `api.exec(name, input, {ticket})`; the
  plugin API version is now 2.
- **`rpc.Specs`** maps every admin method to its params and result types.
  `rpc.Methods()` is its sorted keys. A control test checks the keys
  equal the handler table and each params type equals what the handler
  decodes, so a new method must add a spec.
- **`GET /api/rpc`** adds `schemas: {<method>: {params, result}}` and
  `$defs` (JSON schema built by reflection in `pkg/rpc/rpcschema`,
  named structs as `$ref`s) for the allowed methods.
- **`ui/desk-plugin.d.ts`** is generated by
  `go run ./pkg/rpc/rpcschema/cmd/deskgen` from the same specs plus the
  hand-written `head.d.ts` (api, slots, contexts). `TestDTSCurrent`
  fails when the committed file is stale; that is the CI drift check.
- **`examples/desk-plugins/csv-table`**: plain-JS artifact renderer,
  quoted fields, `textContent` only, first 1000 rows.
- **Docs:** `docs/desk-plugins.md`, linked from the README and
  `jobshop docs desk-plugins`.
